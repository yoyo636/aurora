Aurora 安装完成

寻求将代码转化为智能的最优解。打开终端,开始编程。

验证安装

aurora --version
# ◡ Aurora v1.4.0

创建第一个项目

aurora new hello
cd hello
aurora run

常用命令

aurora run [file]     # 运行 .aur 文件
aurora build           # AOT 编译为 Python
aurora watch           # 文件变化自动运行
aurora test            # 运行测试
aurora repl            # 交互式 REPL
VSCode 插件与 Aurora Dark 主题已自动安装。在 VSCode 中打开 .aur 文件即可获得语法高亮与一键运行。

安装位置: /usr/local/lib/aurora/ · 命令: /usr/local/bin/aurora · AI 文档: /usr/local/lib/aurora/docs/
