Aurora 安装成功!

Aurora 编程语言已安装到你的 Mac。打开终端,开始编程吧!

验证安装:

aurora --version
# Aurora v1.3.0

创建第一个项目:

aurora new hello
cd hello
aurora run

常用命令:

aurora run [file]     # 运行 .aur 文件
aurora build           # AOT 编译为 Python
aurora watch           # 文件变化自动运行
aurora test            # 运行测试
aurora repl            # 交互式 REPL
💡 提示:在 VSCode 中搜索安装「Aurora」插件,获得语法高亮、一键运行等功能。IDE 应用位于项目目录的 Aurora IDE.app。
