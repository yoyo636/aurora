语言特性

  • 表达式导向:if / match / loop / 块都有值,函数最后一个表达式即返回值
  • let / var:不可变与可变绑定,消除 C++ 声明歧义
  • 管道 |>、区间 a..b、defer、yield 生成器
  • 多文件模块:文件即模块,import 本地 .aur,自动搜索 src/
  • 类型系统:type / enum / trait / impl / match 模式匹配
  • 错误处理:Result + ?、panic、assert、契约式编程

标准库(17 个模块)

std.io · std.math · std.str · std.json · std.http · std.web · std.ai · std.python · std.ffi · std.html · std.collections · std.sync · std.time · std.proc · std.result · std.vex

快速开始

aurora new myapp
cd myapp
aurora run

aurora build          # AOT 编译为 Python
aurora watch          # 文件变化自动运行
aurora test           # 运行测试

系统要求

  • macOS 11+(Apple Silicon / Intel)
  • Python 3.8+(macOS 自带)
  • 零第三方依赖
