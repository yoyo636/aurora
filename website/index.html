Example

简洁,而不简单

表达式导向设计,if/match/loop/块都有值,函数最后一个表达式即返回值。

main.aur
// 读取 JSON 配置 → 处理 → 写入结果 let config = json(read("config.json")) let users = config["users"] // 一行完成:提取字段、去重、计算平均值 let names = unique(pluck(users, "name")) let avg_age = avg(pluck(users, "age")) // 管道操作:数据流式处理 let result = users |> filter(fn(u) u["active"]) |> map(fn(u) u["score"] * 2) |> sum() // 一行写入结果 write("result.json", to_json({names: names, avg_age: avg_age, total: result})) println("处理完成: {len(names)} 个用户, 平均年龄 {avg_age}")
Efficiency

Python 十步,Aurora 三四步

同样的任务,更少的代码。全局快捷函数覆盖文件、网络、JSON、字符串、列表、数学等常见操作。

Python — 10 步
1 import json, urllib.request
2 req = urllib.request.Request(url, headers={...})
3 resp = urllib.request.urlopen(req)
4 data = json.loads(resp.read().decode())
5 names = [u["name"] for u in data["users"]]
6 unique_names = list(dict.fromkeys(names))
7 ages = [u["age"] for u in data["users"]]
8 avg_age = sum(ages) / len(ages)
9 with open("out.json", "w") as f: json.dump(..., f)
10 print(f"完成: {len(names)}")
◡ Aurora — 4 步
1 data = json(get(url))
2 names = unique(pluck(data["users"], "name"))
3 avg_age = avg(pluck(data["users"], "age"))
4 write("out.json", to_json({names, avg_age}))
println("完成: {len(names)}")
