开始使用。

一行命令，即刻开始。

$ curl -fsSL https://aurora.dev/install.sh | bash $ aurora --version aurora 5.0.0 $ aurora run hello.aur # VM 模式运行 $ aurora compile hello.aur # AOT 编译为原生机器码
