EXAMPLE

简洁,而不简单

表达式导向设计,if/match/loop/块都有值,函数最后一个表达式即返回值。

main.aur
// 读取 JSON → 处理 → 写入结果(4 步搞定) let data = json(read("config.json")) let names = unique(pluck(data["users"], "name")) let avg_age = avg(pluck(data["users"], "age")) write("result.json", to_json({names: names, avg_age: avg_age})) // 管道操作:数据流式处理 let total = data["users"] |> filter(fn(u) u["active"]) |> map(fn(u) u["score"] * 2) |> sum() println("完成: {len(names)} 用户, 平均 {avg_age} 岁, 总分 {total}")
EFFICIENCY

Python 十步,Aurora 四步

同样的任务,更少的代码。全局快捷函数覆盖文件、网络、JSON、字符串、列表、数学。

PYTHON 10 步
1 import json, urllib.request
2 req = urllib.request.Request(url, headers={...})
3 resp = urllib.request.urlopen(req)
4 data = json.loads(resp.read().decode())
5 names = [u["name"] for u in data["users"]]
6 unique = list(dict.fromkeys(names))
7 ages = [u["age"] for u in data["users"]]
8 avg = sum(ages) / len(ages)
9 with open("out.json","w") as f: json.dump(...,f)
10 print(f"完成: {len(names)}")
AURORA 4 步
1 data = json(get(url))
2 names = unique(pluck(data["users"], "name"))
3 avg = avg(pluck(data["users"], "age"))
4 write("out.json", to_json({names, avg}))
println("完成: {len(names)}")
